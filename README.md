# 知枝 · 交互式知识树

本地运行的中文学习工具。点击知识点逐层展开，右键提问后，问题和回答继续生长在同一张图里。

## 下载安装版

1.2.0 起为独立桌面窗口。未连接时，右上角点击「连接到 Agent」即可选择 Codex、Claude Code 或 API；实际验证成功才显示已连接，失败后可直接重试。

从 [GitHub Releases](https://github.com/mmasondu114/zhizhi/releases/latest) 下载对应平台文件：

| 系统 | 安装文件 | 打开方式 |
|---|---|---|
| Windows 10/11 x64 | windows-x64-setup.exe | 安装后从开始菜单打开「知枝」 |
| macOS 14+、Apple Silicon | macos-arm64.pkg | 安装后从应用程序打开 Zhizhi |

安装版内置 Node.js 和运行依赖，直接打开独立桌面应用窗口，不再启动浏览器。关闭应用窗口时同时退出后台服务。

当前没有开发者代码签名与 Apple 公证，系统可能提示未知发布者。安装包与校验值以正式 Release 附件为准；不要关闭系统全局安全保护。

设置底部可「检查更新」并下载对应系统安装包。升级前退出知枝。Windows 数据位于 `%LOCALAPPDATA%\Zhizhi\data`，Mac 位于 `~/Library/Application Support/Zhizhi`，升级不覆盖学习数据。旧源码版的图可用 JSON 导出/导入迁移。密钥跨账户或系统需要重填。

构建与测试：[Mac](MACOS.md)、[Windows](WINDOWS.md)。

## Windows 从源码启动

双击 **Start.cmd**，然后打开 **http://127.0.0.1:4317**。

从源码启动需要安装 **Node.js 22.12+ 或 24 LTS**，首次启动会运行 `npm ci`。下载依赖需要网络；构建完成后，预置示例与本地文件管理可离线使用。

```powershell
cd "你的项目目录"
.\Start.cmd
```

如果需要停止后台服务：`powershell -NoProfile -ExecutionPolicy Bypass -File .\Stop.ps1`。启动器仅使用本机回环地址；不会部署公网。默认端口占用时，先检查是否已经运行；也可以在启动前设置 `$env:PORT=4318`。

源码运行独立桌面窗口：先 `npm run build`，设置 `$env:TREE_NODE_PATH=(Get-Command node).Source`，再运行 `npm run desktop`。安装版无需这些步骤。

源码修改后：`npm run build`，停止并重启服务。开发热更新：`node server/index.js --dev`。生产运行：`npm start`。

## 学习操作

- 按住鼠标右键拖动可框选知识点，选中项以淡青绿高亮。松开后在鼠标终点弹出操作框，支持复制节点、粘贴副本、标为已理解、折叠与删除。Shift + 右键拖动可追加选择，Esc 取消。单独右键点击仍打开提问菜单。
- Ctrl/Cmd + C 复制所选节点，在本次打开期间用 Ctrl/Cmd + V 粘贴结构副本；系统剪贴板同时获得可读文字。Delete 删除选中节点，保留根节点及未选中的后代，子节点接回仍存在的上级。删除和粘贴均可用 Ctrl/Cmd + Z 撤销。

- 「按教材整理层次」读取并复核全部正文，先列各份 PDF，再按语义组织核心主题与具体概念。每次点击只展开一层，节点数量由内容决定，不固定为 3、6 或 48 个；不逐页、逐题列节点。条件、公式、步骤保留在概念详情。主题与具体概念提前生成并随知识图保存，展开不再调用模型；最终概念点击直接阅读。旧图可重新整理并撤销。图片内容仍依赖 PDF 的文字提取能力。
- 内容编辑停止 3 秒后合并保存，连续编辑最长 15 秒写入一次。平移缩放单独记录视图，不反复保存整张图。确认教材、切换图和退出桌面应用时立即保存；退出保存失败会保留窗口。

- 生成时，节点底部显示 0–100% 的工作进度，按已完成的阅读、复核与整理任务计算。单次模型推理没有已知总长度时，百分比保持在当前步骤，不靠计时假装前进。提示消息在 5 秒后自动消失，生成错误仍可在节点详情中重试。
- 默认开启「预生成」：教材的主题与概念已提前准备；对尚未准备的直接概念分支，在空闲时依次预生成，不固定最多 6 项、不无限递归。点击优先，命中缓存直接展开；右上方可随时关闭。预生成会额外调用所连接的模型并消耗相应额度。缓存只在当前会话内保留最多 10 分钟、30 层；换图、改教材或改模型会清空。

- 初次打开，输入具体目标，或体验 **计算 z-score**。预置模式不调用模型，问答示例明确标注，不会假装是实时回答。
- 单击节点展开一层，已准备的终端概念与原理点击打开详情，再点关闭。分支展开、收起及位置调整有短暂平滑动画，遵循系统减少动画设置。已有子节点时再次单击收起，再次单击展开，复用已有内容、不重复生成；使用节点右下角的 **− / +** 折叠和展开。
- 拖动节点改变位置；在空白处拖动画布。默认 **滚轮直接缩放**，不必按 Ctrl；在画布空白处拖动可上下左右平移。右下角可切换为“滚轮平移”，该模式用 Ctrl + 滚轮缩放。两个模式均使用短促平滑缓动，以指针为缩放中心；模式选择会记住。触屏可平移和捏合。
- **右键、长按或节点的 ···** 打开提问菜单。输入问题后，原始问题成为子节点，回答成为它的子节点。
- **ⓘ** 打开详情，查看解释、公式、例子、引用与学习状态。长文字留在详情中。
- **右键 → 标为重点**（或详情中的“标为重点”）将节点标题、要点和边框标红，可撤销并随图保存、导入导出。解释中的 `**关键短语**` 也会安全显示为红色重点；新的 AI 解释会被要求突出关键条件、结论和易错点。
- 节点标题 18px、要点 15px、详情 16px；卡片随标题、要点和公式自动增高，不截断正文，布局按实际高度留出间距。点击缩放比例回到 100% 阅读字号。关系标签在各自子节点上方，紧凑树布局利用不同层的空白；“整理分支”可重新排布并支持撤销。旧图若与新尺寸冲突，打开时自动整理。
- 左侧搜索会打开必要祖先路径；底部可回根节点、适应全部、聚焦子树、缩放、撤销和重做。
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做。删除分支可以撤销；外部引用的节点保留并重新归属到引用者。
- 生成时画布仍可操作，当前节点显示取消按钮。失败可点击该节点重试。详情中的“重新生成直接分支”会替换已有直接分支，这个操作可以撤销。

## 添加模型

右上角 **连接到 Agent → 本机客户端 → Codex → 连接并使用**，已经登录的客户端不需要填写地址、密钥或模型。若使用 API，选择 **API 接入**，只填服务地址、API Key 和模型名，然后点击 **连接并使用**。模型覆盖、路径和超时放在收起的“高级选项”中。测试是一个实际生成请求，可能消耗提供方额度。切换提供方会取消当前生成请求。

| 提供方 | 如何填写 | 当前验证情况 |
|---|---|---|
| Codex 本地客户端 | 自动检测桌面版与 npm CLI；模型可留空，也可指定；可填写 `.exe` / `.js` 绝对路径 | 本机独立应用→后端→已登录 Codex→知识节点完整链路通过；约 72 秒，生成 4 个 AI 子节点，见 MAC_VALIDATION.md |
| OpenAI-compatible | 填实际 Base URL（通常含 `/v1`）、模型 ID、API Key；本地无密钥服务可以不填 Key | 已做实际 HTTP 协议模拟测试；未使用用户的真实第三方 API 凭据验证 |
| Anthropic API | 默认 `https://api.anthropic.com/v1`，填写实际模型名和凭据 | 独立 Messages 协议测试通过；未进行付费真实请求 |
| Claude Code 本地客户端 | 自动检测，或填可执行文件路径；需在官方客户端完成登录 | 本机未发现可用安装；仅完成参数构造、输出协议与进程管理测试 |

应用检测本机可用客户端，不修改原有全局安装。界面里的连接检测会检查版本与必要参数。Windows 上曾以 `codex-cli 0.167.0-alpha.3.2` 完成真实验证；Mac 客户端登录与生成仍待实机验证。

Codex 通过官方 `exec` 非交互模式运行，使用 `--ignore-user-config`、`--ignore-rules`、`--sandbox read-only`、`--ephemeral`、`--output-schema`，并关闭 shell、apps 与多代理功能。此版本要求客户端支持 `--ignore-user-config`；老版本会显示需要更新。Claude Code 使用 `-p`、JSON schema、空工具集、严格空 MCP 配置并禁用 hooks。两者均通过参数数组和 stdin 调用，不使用 shell 拼接，不读取或导出私有登录凭据。

登录、模型可用性与计费由官方客户端决定。ChatGPT / Claude 订阅不等同于任意第三方 API 的可用额度。

## 教材和范围

“教材”中可以上传 **文本型 PDF、TXT、Markdown、DOCX** 或粘贴正文/目录。最大单文件 20MB。PDF 保留物理页码，其他格式保留段落号。DOCX 不提供虚构页码；空白或无法提取足够文字的 PDF 会提示需要 OCR。

文本按约 1600 字片段拆分，并保留少量重叠。当前使用关键词相关度检索最多 6 段，只发送相关教材、当前节点、最近祖先、学习目标与问题；不会无差别发送整棵树或整本书。已有基础、学习要求与教材分别保存。

对于 `AP Statistics Chapter 3` 这类章节名，优先从用户教材识别范围；教材和范围均选填，无法判断具体主题时会在知识树内询问。Codex 可在设置中开启或关闭联网检索（默认允许），用于核对公开课程大纲和学习任务；不根据通用大纲猜测某本教材的章节内容。教材引用和实际查阅的网页来源在详情中分别显示。

## 保存、备份和导入

- 多图数据存于 `data/graphs/<id>.json`，350ms 防抖、串行原子写入，刷新恢复上次打开的图。
- 浏览器保留当前图的恢复副本。恢复时比较时间，避免旧副本覆盖更新的磁盘文件。保存失败会显示提示和重试入口。
- 点击顶栏图名可切图、重命名、删除。整图删除移入 `data/trash`；需恢复时将对应 JSON 通过“导入”重新打开。
- JSON 导出包含节点、关系、引用、位置、折叠、学习状态、教材和视图，**不包含 API 密钥**。也可导出 Markdown 大纲。
- 数据版本为 `version: 1`。无版本但满足 v1 结构的文件可迁移；未知新版本、循环、重复 ID、孤立节点等会被拒绝，不覆盖现有图。导入创建新图 ID。
- Windows API Key 保存为 DPAPI 密文；Mac 保存到系统钥匙串，设置文件仅记录引用。迁移到另一账户或系统应重新配置密钥。

## 实现与边界

React + React Flow + Vite；Node/Express 本地后端；Zod 结构校验；KaTeX 公式；PDF.js 与 Mammoth 文本提取。图采用确定性自上而下树布局，展开时固定操作节点，调整受影响子树与相邻空间，不使用力导向布局。节点拖动的高频状态与应用面板隔离；缩放到概览级别时简化节点与连线标签。

- “无限深入”指按需要持续生成，而非无穷存储：单图最多 5000 节点，撤销历史最多 40 步。超过数百节点建议折叠或聚焦子树；超大图全览有实际性能退化。
- 当前不内置 OCR。DOCX 的复杂表格、文本框、图中公式可能无法完整提取；数学语义仍应核对原文。
- 检索是关键词方案，未提供向量索引；相同概念的隐喻、跨语言检索可能漏召回。可缩小范围或粘贴相关正文改善。
- AI 内容做结构与引用校验，不能机械保证全部学术结论正确。重要结论应结合教材核对。
- 预置模式覆盖 z-score 的常用深入路径。自由问题仅显示明确标注的示例回答，连接模型后才能得到针对性答案。
- 主布局为树；支持导入引用边并保护被引用节点，但没有额外的“合并两个节点”编辑器。
- 当前适合一个活动编辑窗口。未实现跨标签页并发编辑冲突合并。撤销历史在当前页面内维护，刷新后数据保留但历史不保留。
- macOS ARM 包在 ARM Mac CI 构建和测试；尚未在用户自己的 Mac 上验证模型登录。Linux 暂不提供 API Key 持久保护。
- 详情安全显示文本与公式；不执行模型给出的 HTML、脚本或代码，也不自动打开来源中的链接。

官方接口依据：[Codex 非交互模式](https://developers.openai.com/codex/noninteractive/)、[Claude Code 程序化调用](https://code.claude.com/docs/en/headless)、[Claude Code CLI](https://code.claude.com/docs/en/cli-reference)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)。实际兼容能力以本机 `--help` 检查为准。


### 并行生成与恢复

每份教材独立一路并行（9 份 PDF 即 9 路），每份内部保持批次和复核顺序。受模型服务额度限制时，受限请求最多退避重试 3 次。完整、已验证的响应保存至本机 generation-cache；失败、取消或重开后点击原节点重试，会复用相同上下文及模型的已完成结果（有效期 30 天），不会跳过遗漏复核。长教材单次调用至少允许 5 分钟，最终速度由上游并发和输出速度决定。

桌面显示进程异常时自动尝试重新载入（最多 2 次），从已保存知识图及浏览器恢复副本恢复；未完成的请求可点击重试。desktop.log 记录显示进程和退出原因，server.log 记录生成阶段与耗时。

Windows 可使用 scripts/open-windows.ps1 从桌面 Shell 打开应用，避免将长期桌面窗口挂在临时执行命令下。desktop-session.json 保存会话开始和最后存活时间，用于识别没有触发正常退出事件的中断。模型超时或取消时先等待子进程退出，再重试清理临时目录；清理失败不会覆盖原本的超时错误。

### 核心知识与练习

右键知识点 →「给我一个例子」打开独立练习覆盖页，支持选择、计算和简答。提交前不发送标准答案到页面；提交后显示正误反馈、答案、分步解析和易错点。关闭或按 Esc 回到原知识树，练习不新增节点。「再来一道」生成新题。模型批改仍需结合教材核对。

英文教材的知识点保留专业术语原文，如“抽样分布（Sampling distribution）”。较长术语和多个概念的对照放在详情，解释仍用中文；练习与解析沿用教材术语。
